Описание проекта

Скрипт для автоматизированного получения и обработки данных о земельных участках из НСПД по списку кадастровых номеров.

Проект:

загружает геометрию участков
конвертирует данные в формат GeoJSON
извлекает ключевые атрибуты (площадь, кадастровая стоимость)
рассчитывает стоимость за квадратный метр
формирует готовый набор данных для анализа в QGIS

Используется для визуализации и анализа рынка недвижимости (heatmap, choropleth-карты, пространственная аналитика).

Технологии

Python
pynspd
shapely
GeoJSON
QGIS

Цель

Демонстрация применения методов автоматизированной обработки геоданных и ГИС-технологий для анализа земельных участков с соблюдением ограничений НСПД.

Входные данные
не забудьте установить зависимости
pip install -r requirements.txt

список кадастровых номеров `cad_list.txt` (в данном файле их 10 можете загружать туда свои)

Выходные данные

 `analyzed.geojson` — геоданные участков
 `errors.txt` — список ошибок обработки
