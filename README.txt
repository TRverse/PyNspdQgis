Парсер кадастровых участков (НСПД)

Скрипт обходит квадрат на карте, собирает кадастровые номера участков и получает по каждому геометрию и свойства через НСПД (Росреестр). Результат сохраняется в GeoJSON.


Как работает
Этап 1. По сетке точек делаются запросы к map.ru, из ответов берутся кадастровые номера. Дубли удаляются. Результат: cad_list.txt и gagarinsky_7km.csv.
Этап 2. Каждый номер проверяется через pynspd (НСПД). Результат: analyzed.geojson с геометрией, площадью, кадастровой стоимостью и ценой за м².


Ошибки пишутся в errors.txt (номера, которые не нашлись в НСПД) и в failed_points.txt (точки сетки, где запрос не прошел).


Установка
pip install -r requirements.txt

Запуск
python parser.py


Настройки находятся в начале parser.py:

CENTER_X, CENTER_Y	Центр квадрата, EPSG:3857

SIZE_METERS	Сторона квадрата, м

STEP	Шаг сетки, м. Меньше шаг: меньше пропусков, но дольше

CAD_PREFIX	Оставлять только номера с этим кварталом (например, 91:02)

WORKERS	Число потоков на этапе 1

RETRIES	Число попыток на запрос

NSPD_PAUSE	Пауза между запросами к НСПД, сек


Что нового:

В requirements.txt добавлены requests и tqdm.
Ограничения
Точечный обход сетки не гарантирует нахождение всех участков. Очень мелкие участки можно поймать, уменьшив STEP.
У НСПД есть лимиты на запросы, большие области обрабатываются долго.
